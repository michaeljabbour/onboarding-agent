# Third-party notices

The application uses Node.js built-in modules and browser APIs. It does not bundle a JavaScript framework, model weights, font files, or third-party artwork. Its font stacks refer to fonts already installed on the user's device.

The launcher can download Node.js from its official distribution service and install Claude Code through Anthropic's official installer. These are separate products under their respective terms; the MIT license for this repository does not relicense them. A supported Claude account or configured provider is required for model replies.

The teaching, practice, and feedback approach was informed by studying [Primer](https://github.com/wharton-generative-ai-labs/primer) and its [learning modules](https://github.com/wharton-generative-ai-labs/primer-modules) from Wharton Generative AI Labs. The Climb uses original code, wording, and visuals; no Primer code, prompts, or assets are distributed here.
